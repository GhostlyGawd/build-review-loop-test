# Prospective conformance fixture

`golden-run.json` is synthetic protocol evidence used only to test execution-mode validation. It demonstrates two distinct ephemeral CLI processes, raw JSONL/hash/usage reconciliation, deterministic post-model visible-filesystem snapshot bindings, a schema-valid blinded-package manifest, exact argv/prompt bindings, sequential one-package evaluator seals, lifecycle completion, and a valid completed run. It preserves the collaboration-dispatch failure and CLI v1-v3 rehearsals as unscored historical invalid attempts. `invalid-current.json` demonstrates a currently invalid run with structured evidence commitments and no evaluation conclusion or scored outcome. The fixture is not proof of a final runner smoke; those three lock commitments remain null.

Their identifiers and snapshots are deterministically derived test values, not candidate output, hidden-suite input, or experiment evidence. They must never be interpreted as executed experiments.
